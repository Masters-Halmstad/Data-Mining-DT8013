Step 4: Do the following tasks:

1-Data pre-processing: Clean the dataset, handle missing values (if any), find anomalies via different unsupervised methods, and check if you can justify the anomalies using external information (either in the dataset or using external resources, e.g., low bike rental due to cold weather).

2- Provide a summary of the dataset via descriptive statistics.

3- Apply relevant dimension reduction and data visualization tools to show essential insights and trends in the data.

4- Ask a "research question" and use learned tools to respond to the question (it should be a clear and creative question to discover hidden patterns and relationships, and show exciting insights within a dataset)

5. Feature Engineering: Extract relevant features from the dataset that could impact the outcome (e.g., time of the year, promotions, holidays, etc.) to enrich the dataset.

6- Presentation and Report: Create a report detailing the entire process—maximum number of pages: 3, Calibri (Body), Font size 11.

7- Prepare a presentation summarizing the key findings, challenges faced, and recommendations. 15 slides max, 15 minutes for each group (15 minutes presentation followed by 5 min questions). 

Note: If you run out of your 15 minutes, you will be stopped. So it is advised that you practice your presentation to finish it on time.
